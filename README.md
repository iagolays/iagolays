## 📋 Política de uso dos apuntes

Estes apuntes son creación propia e compártoos de forma libre baixo as seguintes condicións:

✅ **Permitido**
- Lelos, descargarlos e usalos como material de estudo e referencia
- Inspirarse neles para elaborar os teus propios apuntes
- Compartilos con outros estudantes citando a fonte

❌ **Non permitido**
- Presentalos como traballo propio en exames, prácticas ou entregas (plaxio)
- Vendelos ou obter calquera beneficio económico con eles
- Redistribuílos de forma masiva sen mencionar a autoría
